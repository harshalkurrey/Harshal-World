## 🎯 About the Project

**Harshal World** is a personal arcade gaming hub that runs entirely in the browser —
no installs, no sign-ups, just open and play. Built from scratch using vanilla
HTML, CSS, and JavaScript, it features multiple playable canvas-based games,
an XP & rank progression system, a leaderboard, and synthesized in-game audio.

This project is a showcase of what's possible with pure frontend development —
proving that powerful, immersive experiences don't always need a framework.

---

## ✨ Features

- 🎮 Multiple playable arcade games — each with unique themes & mechanics
- 🏆 XP & Rank progression system — level up as you play
- 📊 Leaderboard — track your high scores
- 🔊 Synthesized in-game audio — no external audio files needed
- 🎨 Unique visual themes — Deep Sea, Pixel Dungeon, Sunset Circuit & more
- 📱 Mobile-friendly & responsive design
- ⚡ Zero dependencies — pure HTML, CSS & JavaScript only
- 🚀 Deployed via GitHub Pages — instant access, no setup

## 🛠️ Tech Stack

| Technology | Role |
